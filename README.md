# Bancolombia Investment Analytics

Prueba técnica - Analítica de Inversiones
Vicepresidencia de Estructuración de Mercado de Capitales

## Objetivo
Desarrollar una herramienta analítica para consultar,
consolidar y analizar portafolios de inversión locales
(COP) e internacionales (USD).

## Tecnologías
- Python 3.13
- PostgreSQL
- Django
- Docker Compose
- SQL
- Bootstrap y Plotly
- Scikit-learn

## Estado
Fase 1: Preparación del entorno de desarrollo.

## Seguridad
Los archivos CSV originales y las credenciales
no forman parte del repositorio.
